Примерный график XO
XO Sample Graph — настольное приложение для Windows для навигации по библиотеке аудиосемплов в стиле XLN XO.

Программа индексирует выбранную папку с аудиосемплами и отображает их на интерактивном холсте в виде цветных маркеров. Цвет маркера соответствует категории звука (Kick, Snare, Hi-Hat, Percussion, Bass, Vocal и др.), что позволяет быстро ориентироваться в большой коллекции сэмплов.

Возможности
🎨 Визуальное отображение библиотеки сэмплов на холсте.
🟢 Цветовая классификация по типу звука.
▶️ Предварительное прослушивание сэмплов.
🎧 Одновременное воспроизведение нескольких сэмплов (режим Fade).
📂 Выбор папки для индексации.
📁 Открытие файла в Проводнике Windows.
🎵 Открытие сэмпла в AIMP.
🔍 Масштабирование интерфейса (100%, 150%, 200%).
